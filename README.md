# Homestead HOA Dues Portal

This repository hosts the public webpage for the Homestead HOA dues-status portal.

## Privacy

- The public website does **not** contain the HOA workbook, resident list, names, contact details, payment amounts, payment history, or access codes.
- A resident must provide both a house number and an individual access code to request a status.
- The portal returns only a simplified result for the requesting household: paid, needs attention, or under review.
- The system is designed not to disclose information about other households.

## Public documents

The public site includes a meeting-minutes archive placeholder. Any CCR PDF or approved meeting minute published beneath `site/` is public, downloadable, and retained in Git history. Do not add documents until they have been reviewed for public release.

For help with a dues question or access code, contact the HOA at [homesteaddrivehoa@gmail.com](mailto:homesteaddrivehoa@gmail.com).
